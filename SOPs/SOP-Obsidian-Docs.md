# SOP — Documentación en Obsidian

Fecha: 2026-08-22

## Propósito
Estandarizar cómo se documenta todo el trabajo de Beekonz.

## Reglas
1. Todo conocimiento nuevo (research, campañas, análisis, aprendizajes) se documenta en la carpeta correspondiente:
   Brand/ Products/ Marketing/ Content/ Discord/ Community/ Research/ Competitors/ SOPs/ Analytics/ Launches/ Ideas/ Partnerships/
2. Todo documento incluye estas secciones obligatorias:
   - **Fecha**
   - **Resumen**
   - **Hallazgos**
   - **Acciones recomendadas**
   - **Próximos pasos** (checklist `- [ ]`)
3. Usar wikilinks `[[...]]` entre documentos relacionados.
4. Un tema = un archivo. Los dashboards agregan y linkean fichas individuales.
5. Antes de proponer estrategia: verificar contexto en README.md y preguntar lo faltante.
