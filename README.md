## ¿Qué es Beekonz?

Beekonz es una marca enfocada en Virtual Reality (VR), específicamente en **Full Body Tracking** para VRChat y otros ecosistemas de realidad virtual.

**Misión:** crear trackers accesibles, ligeros, precisos y con excelente experiencia de usuario para la comunidad VR.

**Posicionamiento:** referencia dentro del ecosistema SlimeVR / VRChat / Full Body Tracking.

## Sitio web

https://beekonz.com — centro principal de la marca.

## Producto principal: Smols LSM6DSV

Trackers ultraligeros para Full Body Tracking:

- Sensor: LSM6DSV
- Peso aprox.: 10 g
- +50 h de batería
- Tecnología basada en SlimeVR
- Diseñados para VRChat y FBT accesible

## Componentes técnicos

- **Sensor:** LSM6DSV (se evaluó ICM-45686 antes; dirección actual = LSM6DSV). Placas de **DTQSYS**.
- **Dongle:** nRF52840 USB (comunicación inalámbrica).
- **Batería:** 401230 — 3.7 V, 115 mAh. Objetivo: máxima autonomía con mínimo peso.
